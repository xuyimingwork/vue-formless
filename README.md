# vue-formx

简体中文 | [English](./README.en.md)

> Vue 3 表单组合式 hooks（脚手架占位，尚未发布 API）。

## 特性

- Vue 3.3+ Composition API hooks
- TypeScript 编写：提供完整类型定义
- 零运行时依赖目标：不依赖第三方 npm 包（除 Vue peer）

## 安装

```bash
pnpm add vue-formx
# or
npm install vue-formx
```

## 开发

```bash
pnpm i
pnpm build
pnpm test
pnpm typecheck
```
